HCT 1.6 v2.2.3 - A MOD FOR HORIZON CHASE TURBO (STEAM)
=====================================================

INSTALL
  1. Close the game.
  2. Double-click INSTALL.cmd.
     It finds the game in your Steam libraries on its own. If it cannot, it asks for the folder
     (the one that contains HorizonChase.exe).
  3. Start Horizon Chase Turbo from Steam as usual. The title screen shows "HCT 1.6 v2.2.3 MOD ACTIVE".
     The mod's campaigns (Chile, Rutas de Chile, Aventura Chile, Competencia Chile 2026, Grand Prix 2026)
     are under Campaigns.

REMOVE
  Double-click UNINSTALL.cmd. It deletes only what the installer added; the game is left as Steam
  installed it. It asks whether you also want to delete the mod's saves.

WHAT IT DOES AND DOES NOT DO
  - It changes no game file: it only adds files to the game folder (the list is kept in
    HCT15-installed.txt). It uses BepInEx 5, the free mod loader (LGPL-2.1,
    https://github.com/BepInEx/BepInEx).
  - Your Steam save is not touched: the mod keeps its own progress apart, in the game's HCT15Saves folder.
  - It unlocks no paid content. The Grand Prix 2026 campaign uses the cars of the Senna Forever DLC and
    only shows up if you own it.
  - What you play with the mod's content is not sent to Steam leaderboards and does not count for
    achievements or statistics. The game's own modes work exactly as before.
  - Steam's "Verify integrity of game files" does not remove the mod (it touches no game file).

IF SOMETHING GOES WRONG
  - The loader's log is <game folder>\BepInEx\LogOutput.log.
  - If Steam updates the game, the installer warns you when the game files changed; the mod may need
    a new release.

A free, non-commercial fan mod. It contains no files of Horizon Chase Turbo (by Aquiris Game Studio):
you need your own copy of the game. Data and photo credits: CREDITS.txt in the repository.
