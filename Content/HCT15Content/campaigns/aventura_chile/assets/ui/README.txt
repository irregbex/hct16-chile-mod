HCT 1.6 - UI graphics of the campaign screens
=============================================
<name>.png    a replacement for one of the game's campaign-screen graphics: give it the same file name as the
              game's sprite and place it directly in this folder. It replaces that graphic on every screen where
              it appears, whatever its size. background.png is the campaign's own background.

The mod ships no graphics of the game. To see the names of the game's sprites on your own copy, start the game
with -hct15-dumpgame: the mod then writes them, for your reference only, into originals\ next to this file
(never commit or share that folder).
Without a replacement the mod shows ..\logo.png where the game would show its own campaign header.
